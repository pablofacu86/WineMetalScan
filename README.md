# WineMetalScan — prediction app (Posit Connect Cloud)

Shiny app to estimate potassium, magnesium and calcium (regression) and
classify iron and copper (above/below their limit of interest) in wine from
an FT-MIR spectrum, using the models validated in the study.

## Expected structure

```
app.R
R/predict_utils.R
Models/            <- generated by Build_Deployment_Models.R (POTASSIUM_model.rds, etc.)
data/
  Test_Set_App.xlsx
www/
  ivagro_logo.png             <- IVAGRO logo
  uca_logo.png                <- University of Cadiz logo
```

**Before deploying**, run `Build_Deployment_Models.R` (in the code repo;
already updated to also compute the dendrogram data for iron and copper)
and copy the 5 resulting `.rds` files to `Models/`. Without those files,
each tab still loads and shows the scope information, but "View validation
status" and the prediction panel show a notice that the model is not
available yet, instead of breaking the app.

**Important:** `.rds` files generated before this change do not include
the dendrogram data. The app does not break with them — it simply shows
"Dendrogram not available for this model" on the iron and copper tabs
until `Build_Deployment_Models.R` is re-run and those two `.rds` files are
replaced.

## Required R packages

`shiny`, `bslib` (>= 0.5, for `page_navbar`/`nav_panel`/`layout_columns`),
`DT`, `ggplot2`, `openxlsx`, `prospectr`, `caret`, `xgboost`, `dendextend`,
`circlize`, and `kernlab` installed (used internally by `caret` for the SVM
models, no need to load it with `library()`).

## How prediction on a new spectrum works

1. The user uploads a file (.csv or .xlsx) with wavenumber and absorbance,
   or a file with the same row format as the study's datasets (ID,
   reference value, 545 variables).
2. The spectrum is **realigned by linear interpolation** to the model's
   reference grid (902.57-3000.84 cm-1, ~3.86 cm-1 step). This is what
   allows accepting spectra from a different instrument, with a slightly
   different sampling step or range — as long as it reasonably covers the
   900-3000 cm-1 region; if coverage is below 90% a warning is shown that
   the prediction may not be reliable.
3. Exactly the same preprocessing used to train that analyte's winning
   model is applied (derivative, SNV or MSC with the stored training
   reference, cropping to the Patz windows, centring, Boruta variables if
   applicable).
4. The loaded model predicts. For regression, an approximate 95% interval
   is also reported as value +/- 2xRMSE of the test set (a simple
   approximation, not a statistically rigorous prediction interval —
   stated as such in the downloadable report). For classification, the
   predicted class and the probability of each class are shown.

## Limitations to keep in mind

- The "+/- 2xRMSE" interval assumes the prediction error is approximately
  normal and constant across the whole concentration range, which is a
  reasonable simplification but not a formal statistical guarantee.
- Realignment by interpolation helps with grid differences, but does not
  correct deeper differences between instruments (baseline, optical
  resolution, signal-to-noise ratio). Whenever possible, it is recommended
  to validate with samples of known concentration from the instrument in
  use before trusting routine predictions (that is what the samples in
  `data/Test_Set_App.xlsx`, with known reference values, are for).
